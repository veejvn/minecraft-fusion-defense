## Shared Power Crystal activation

Drag/drop **one Power Crystal** per valid activation, immediate, no cooldown. Invalid drop or invalid target-dependent commit rejects without Crystal consumption. Self-buff/shield can activate without Enemy. Same-tick activations sequential and atomic. Per-ability targeting, stable Entity ID ties and eligibility recheck.

## Cross-cutting rules

- Same-source statuses refresh; distinct sources remain independent per ability rules.
- Stun pauses unfinished multihit cadence without burst; fired projectiles persist when specified.
- Armor/Resistance → Redirect → Shield → HP, subject to typed piercing exceptions.
- Zero-damage valid hit may apply Burn; projectile hit claim and Damage Commit are atomic.
- Shield oldest-first; recast same-source Shield retains original instance ID and creation order.
- Snapshot status, projectiles, queue, RNG, versions and IDs for deterministic recovery.
- RECOVERING rejects new gameplay inputs and does not replay uncommitted inputs.
