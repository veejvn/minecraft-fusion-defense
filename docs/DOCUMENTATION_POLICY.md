# Documentation authority

**Confirmed by Owner; effective 2026-11-14.** Markdown documents under `docs/` in this GitHub repository are the sole authoritative project documentation. Notion authority and synchronization requirements are retired. Historical Notion links are archival references only and are never prerequisites for development or approval.

Read current repository decision records and relevant catalogs before changing project behavior. Preserve existing Owner-confirmed decisions. `Draft`, `Proposed`, `Prototype`, and `TBD` are unapproved; a commit, timestamp, or presence in this repository does not itself confer approval. When current documents conflict, report the conflict and ask the Owner rather than choosing a gameplay interpretation. The Owner's current explicit request takes priority.

See [PGD-01](decisions/PGD-01-STEEL-GUARDIAN.md) for the confirmed Steel Guardian identity and the gameplay details still open.
